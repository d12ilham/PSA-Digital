# Correctional Services Report Workspace

This folder is the isolated workspace for the **Correctional Services Workforce Insights Report**.
Developers working on this report can build views entirely inside this directory.

## Scope:
- **Custodial Corrections** (Prisons, Youth Justice, Detention Centers)
- **Community Corrections** (Probation, Parole, Offender Rehabilitation)

## Directory Structure:
- `views/`: Add chapter views here (e.g. `CorrectionalServicesExecutiveSummaryView.tsx`, `CorrectionalServicesIntroductionView.tsx`).
- `index.ts`: Export view components.
- `data/`: (Optional) Mock data or year-specific data files.
