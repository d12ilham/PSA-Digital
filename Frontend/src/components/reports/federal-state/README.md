# Federal and State/Territory Government Report Workspace

This folder is the isolated workspace for the **Federal and State/Territory Government Workforce Insights Report**.
Developers working on this report can build views entirely inside this directory.

## Scope:
- **Federal Government Departments & Agencies**
- **State and Territory Public Sector Workforces**

## Directory Structure:
- `views/`: Add chapter views here (e.g. `FederalStateExecutiveSummaryView.tsx`, `FederalStateIntroductionView.tsx`).
- `index.ts`: Export view components.
- `data/`: (Optional) Mock data or year-specific data files.
